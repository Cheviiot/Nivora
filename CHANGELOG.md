# История изменений

Здесь перечислены изменения, которые влияют на установку и использование каталога. Версии приложений приведены в [витрине](README.md), а изменения отдельных рецептов — в [истории main](https://github.com/Cheviiot/Nivora/commits/main/).

## 18 ноября 2026

- Лицензия и ссылка на условия теперь находятся рядом с командой установки в README каждого пакета. Подключение каталога и диагностика объединены в [руководстве пользователя](.github/docs/installation.md).
- При первой установке каждого пакета RPM выводит тип лицензии и путь к её материалам. Для проприетарных приложений уточнены уведомления Stapler и ссылки на условия разработчиков.
- Для GNOME Software добавлен [служебный плагин Stapler](gnome-software-plugin-stplr/README.md). Он заменяет штатный плагин p11 и поддерживает открытие установленных приложений. Карточки сверяются с desktop-файлами и иконками собранных RPM.
- PineconeMC получил собственные метаданные приложения. Добавлены официальные снимки интерфейса PineconeMC и Telegram. ChatGPT устанавливает локализованные метаданные из каталога.
- Parsec сохраняет выбор режима клавиатуры. Happ сохраняет состояние службы при обновлении и отключает её при удалении. Tailscale сохраняет изменённые параметры службы.
- Основные проверки перешли на Stapler 0.2.0. Обновлены подготовка инструментов, работа с зеркалами p11, проверка целостности RPM и восстановление автоматических обновлений.

## 17 ноября 2026

- Каталог переведён на ALT Linux p11. Удалены Casement, DistroShelf и GitHub Desktop.
- Витрина объединяет приложения по категориям и показывает архитектуры из рецептов. Сопровождение и автоматическая публикация ведутся в `main`.
- Добавлены почасовой поиск обновлений и ежедневная проверка всего каталога. [Расписание и восстановление](.github/docs/maintenance.md)
