# AniDesk

Неофициальный клиент Anixart для просмотра аниме на компьютере. Во встроенном плеере можно смотреть видео под своей учётной записью Anixart и включить улучшение изображения Anime4K. [Проект AniDesk](https://github.com/theDesConnet/AniDesk)

ALT Linux p11 · x86_64

## Установка

**Лицензия приложения** — [GPL-2.0-only](https://github.com/theDesConnet/AniDesk/blob/main/LICENSE).

```bash
sudo stplr install nivora/anidesk
```

## Запуск

Откройте AniDesk из меню или выполните `anidesk`. Если приложение завершается при запуске из-за графического драйвера, попробуйте `ANIDESK_DISABLE_GPU=1 anidesk`. В этом режиме ускорение Anime4K недоступно.
