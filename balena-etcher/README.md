# balenaEtcher

Утилита для записи образов операционных систем на флешки и SD-карты. После записи Etcher сверяет данные на носителе с образом. [Сайт balenaEtcher](https://etcher.balena.io/)

ALT Linux p11 · x86_64

## Установка

**Лицензия приложения** — [Apache-2.0](https://github.com/balena-io/etcher/blob/master/LICENSE).

```bash
sudo stplr install nivora/balena-etcher
```

## Запуск

Откройте balenaEtcher из меню или выполните `balena-etcher`. Выберите образ и проверьте модель и объём целевого накопителя перед записью. Его содержимое будет перезаписано.
