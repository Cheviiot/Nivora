## Установка

```bash
sudo stplr install nivora/fisher
```

## Возможности

[Fisher](https://github.com/jorgebucaran/fisher) — менеджер плагинов для Fish
shell. Ноль конфигурации, чистый Fish, параллельная загрузка плагинов.

## Технические детали

Пакет устанавливает единственный файл `fisher.fish` в
`/usr/share/fish/vendor_functions.d/` — штатный vendor-каталог автозагрузки
функций Fish. Отдельного демона, сервиса или post-install шага не требуется:
функция `fisher` становится доступна в любой новой сессии Fish сразу после
установки.
