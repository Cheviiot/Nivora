# Happ

Happ подключается к прокси-серверам по вашей конфигурации или ссылке на подписку. Клиент использует ядро Xray. [Сайт Happ](https://happ.info/)

ALT Linux p11 · x86_64 · aarch64 (предварительная поддержка)

## Установка

**Лицензия приложения** — проприетарная. Клиент распространяется бесплатно. При интерактивной сборке Stapler предлагает принять [условия Happ](https://happ.info/main/terms-of-services).

```bash
sudo stplr install nivora/happ
```

## Запуск

Откройте Happ из меню или выполните `happ`. При первой установке пакет включает и запускает службу подключения. Её состояние можно проверить командой `systemctl status happd.service`. Импортируйте конфигурацию своего сервера или ссылку на подписку, выберите профиль и подключитесь.
