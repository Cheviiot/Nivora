# Kimi Code Desktop

Официальное [десктопное приложение Kimi Code](https://www.kimi.com/code) —
AI-агент для работы с кодом от Moonshot AI. Nivora упаковывает официальный
Linux DEB для ALT Linux p11 и Sisyphus; доступна архитектура `amd64`.

## Установка

```bash
sudo stplr install nivora/kimi-code
```

Запустите **Kimi Code** из меню приложений или командой `kimi-code`.
Для работы потребуется войти в учётную запись Kimi. Сессии, проекты и
настройки остаются в пользовательском профиле и не удаляются вместе с пакетом.

Пакет устанавливает именно графическое приложение. Терминальный агент
Kimi Code CLI (`kimi`) в него не входит.

Источник: официальная страница загрузки Moonshot AI,
[первый Linux-релиз 1.1.0](https://www.kimi.com/code/docs/en/kimi-code-desktop/changelog.html).
Лицензия приложения — проприетарная: [условия Kimi](https://www.kimi.com/terms).
