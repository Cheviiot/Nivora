# OpenCode Desktop

Официальное [десктопное приложение OpenCode](https://opencode.ai/download)
для работы с кодом через AI-агента. Nivora упаковывает официальный Linux DEB
для ALT Linux p11 и Sisyphus; доступны `amd64` и `arm64`.

## Установка

```bash
sudo stplr install nivora/opencode
```

Запустите **OpenCode** из меню приложений или командой `opencode-desktop`.
Для работы потребуется настроить провайдера модели в приложении. Учётные
данные и проекты остаются в пользовательском профиле и не удаляются вместе
с пакетом.

Пакет устанавливает именно графическое приложение. Терминальная команда
`opencode` в него не входит.
