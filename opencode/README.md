# OpenCode

Настольный ИИ-агент для работы с кодом. Откройте папку проекта, ведите отдельные сессии для разных задач и просматривайте предложенные изменения по файлам. [Сайт OpenCode](https://opencode.ai/)

ALT Linux p11 · x86_64 · aarch64 (предварительная поддержка)

## Установка

**Лицензия** — [MIT](LICENSE). Для доступа к моделям действуют условия выбранного провайдера.

```bash
sudo stplr install nivora/opencode
```

## Запуск

Откройте **OpenCode** из меню или выполните `opencode-desktop`. В приложении выберите модель. Чтобы использовать свой ключ API или подписку, подключите соответствующего провайдера. [Настройка провайдеров](https://opencode.ai/docs/providers/)

[Подключение Nivora](../.github/docs/installation.md) · [Каталог приложений](../README.md)
