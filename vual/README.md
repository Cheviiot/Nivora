## Установка

```bash
sudo stplr install nivora/vual
```

## Возможности

[Vual](https://github.com/Cheviiot/Vual) — GTK4/libadwaita-приложение для
запуска Cheat Engine в Steam-играх через Proton:

- отображает библиотеку Steam с обложками игр;
- настраивает `LaunchOptions` для `protonhax` одним кликом;
- умеет самостоятельно скачать и установить Cheat Engine.

## Технические детали

Пакет архитектурно-независим (`all`) — это Python/GTK4-приложение без
скомпилированных под конкретную архитектуру бинарников.
