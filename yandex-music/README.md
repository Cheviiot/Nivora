# Яндекс Музыка

Настольный клиент Яндекс Музыки с доступом к коллекции, плейлистам и персональным рекомендациям «Моей волны». Для прослушивания нужна подписка Яндекс Плюс или другая подписка, которая её включает. [Приложение для компьютера](https://music.yandex.ru/download/)

ALT Linux p11 · x86_64

## Установка

**Лицензия** — проприетарная. При интерактивной сборке Stapler покажет ссылку на [лицензионное соглашение Яндекс Музыки](https://yandex.ru/legal/music_mobile_agreement/) и запросит подтверждение.

```bash
sudo stplr install nivora/yandex-music
```

## Запуск

Откройте **Яндекс Музыку** из меню или выполните `yandex-music`. Войдите с Яндекс ID, к которому привязана подписка. Новые версии приложения устанавливаются через Stapler.
