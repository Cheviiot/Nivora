# Яндекс Музыка

Официальное приложение Яндекс Музыки для прослушивания музыки, персональных рекомендаций и «Моей волны» на компьютере.

[Официальный сайт и описание](https://music.yandex.ru/download/) · [Лицензия](LICENSE)

**Платформа:** ALT Linux p11.

**Архитектуры:** amd64.

## Установка

Сначала [подключите Nivora](../.github/docs/installation.md#2-подключить-nivora),
затем выполните:

```bash
sudo stplr install nivora/yandex-music
```

Текущая версия указана в [каталоге](../README.md#каталог).
[Обновление и удаление](../.github/docs/installation.md) выполняются через Stapler.

## Запуск

Откройте приложение из меню или выполните от своего пользователя:

```bash
yandex-music
```

Для прослушивания музыки нужна подписка Яндекс Плюс или другая подписка, включающая доступ к сервису.

[Каталог Nivora](../README.md) · [Помощь](../.github/docs/troubleshooting.md)
